title: "Local development"
description: "Run frontend and engine locally, with or without Docker."
---

## Docker workflow

Use this default loop.

```bash
docker-compose --env-file .env.dev up --build
```

Services:

- `frontend`: Next.js dev server on port `3000`
- `engine`: ts-node-dev service on port `3001`

The compose file mounts source directories for hot reload.

## Non-Docker workflow

You can run each package directly.

### Frontend

```bash
cd frontend
npm ci
npm run dev
```

### Engine

```bash
cd engine
npm ci
npm run dev
```

## Local CI script

From repository root:

```bash
node scripts/ci.js
```

This runs lint, tests, and builds for both `frontend` and `engine`.

## Useful commands

```bash
# Frontend
cd frontend
npm run lint
npm run test
npm run test:coverage
npm run build

# Engine
cd engine
npm run lint
npm run test
npm run test:coverage
npm run build
```
