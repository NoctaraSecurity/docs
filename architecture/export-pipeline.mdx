title: "Export pipeline"
description: "How Noctara creates PDF, DOCX, and Markdown outputs."
---

Noctara exports are generated by `ExportService` in `frontend/src/lib/export/services/ExportService.ts`.

## Export flow

1. Validate requested format (`pdf`, `docx`, `md`).
2. Load project, uploads, report blocks, and company context.
3. Generate company logo signed URL (if present).
4. Curate findings with `ReportCurator`.
5. Transform to unified document data model.
6. Build section contract for document output.
7. Render through format-specific builder.

## API interface

Exports are served from:

`GET /api/reports/export/[projectId]?format=pdf|docx|md`

The response is binary with `Content-Disposition` attachment headers.

## Access control model

The API route requires authenticated user context.

Data fetches rely on RLS in Supabase, so users only export projects they can access.
