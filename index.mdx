Noctara is an AI-assisted security analysis platform. You upload scanner output, and Noctara produces structured findings, CVE enrichment, risk scoring, and export-ready reports.

## What you can do

- Upload security artifacts (`.txt`, `.xml`, `.log`, `.nmap`, `.json`) up to 50 MB each.
- Process files through a workflow that detects tool type, extracts findings, enriches with CVE and EPSS, and generates a structured report.
- Manage projects by company context so reports are grounded in business and infrastructure details.
- Use token billing with redemption codes and admin controls.
- Export reports as PDF, DOCX, or Markdown.

## Core workflow

1. You upload a file in a project.
2. Noctara computes token cost (`1 token = 2,500 characters`) and waits for confirmation.
3. After confirmation, Noctara calls the engine webhook.
4. The engine runs the LangGraph pipeline and writes `report_blocks`.
5. The UI updates in real time through Supabase Realtime.

## System components

- `frontend/`: Next.js 16 app for auth, dashboard, projects, tokens, admin, and exports.
- `engine/`: Node.js service that handles webhook processing and report generation.
- `supabase/`: SQL migrations for schema, RLS, storage, token billing, and company context.
