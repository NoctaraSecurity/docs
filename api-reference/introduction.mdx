Noctara exposes a small set of HTTP endpoints across engine and frontend runtime.

## Endpoint summary

| Endpoint | Runtime | Purpose |
| --- | --- | --- |
| `GET /health` | Engine | Health probe |
| `POST /api/process-file` | Engine | Upload processing webhook |
| `GET /api/reports/export/[projectId]?format=...` | Frontend | Report export as file download |

## Authentication model

- Engine webhook endpoint validates `X-Webhook-Secret` when configured.
- Export endpoint requires authenticated user session and RLS-compliant project access.
